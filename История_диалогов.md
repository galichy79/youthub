# История диалогов — YouHub

**YouHub** — консольный YouTube-клиент: TUI-сетка превью (kitty graphics protocol), воспроизведение до 1080p60 через реверс-инженерный протокол SABR, кастомный плеер `ffplay-yt` (форк FFplay 4.3.9 с IPC), рекомендации, поиск, SponsorBlock, watchstats. Без браузера и без yt-dlp в пути воспроизведения.

- Точка входа: `grid_demo.py`
- Окружение: Python 3.11 (`.venv`), Node.js ≥ 18, системный FFmpeg, kitty, X11
- Репозиторий: https://github.com/HelpFreedom/youthub.git

### 2026-09-30 — Лаунчер для рабочего стола

**Запрос:** написать шелл-скрипт для запуска и положить на рабочий стол.

**Создан:** `/home/u/Desktop/YouHub.sh` (chmod +x). Написан в стиле соседнего `Зеркало-телефона.sh`: `set -uo pipefail`, хелперы `notify()`/`die()`, проверки зависимостей, защита от повторного запуска, wait-петля, лог `~/.cache/youthub-launch.log`.

**Логика:**
- проверка `~/youthub`, `.venv/bin/python3.11`, `grid_demo.py`;
- защита от повторного запуска: `pgrep -f "python3[.]11 grid_demo.py"` (квадратные скобки — чтобы pgrep не совпал с собственной командной строкой);
- если вызван изнутри kitty (`KITTY_WINDOW_ID` + TTY) → `exec` в текущем окне; иначе → `nohup kitty -T YouHub … &` + `disown`;
- ожидание до 10 с с проверкой, что процесс поднялся.

**Ключевое решение:** ветка «новое окно kitty» обязательна — двойной щелчок по `.sh` в Cinnamon запускает его вне kitty, где kitty graphics protocol недоступен и превью не отрисуются.

**Проверено в рантайме:**

| Сценарий | Результат |
|---|---|
| Уже запущен | exit=0, второе окно не появилось ✓ |
| С рабочего стола (новое окно kitty) | окно открылось, сетка отрисовалась ✓ |
| Изнутри kitty (`exec`) | bash заменён на python, лишнего процесса нет ✓ |

**Не сделано:** `.desktop`-файл для двойного щелчка без диалога Cinnamon (у `Зеркало-телефона` такой есть). Предложено пользователю.
